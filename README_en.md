# Migrating a MySQL cluster through Yandex Data Transfer

With [Data Transfer](https://yandex.cloud/docs/data-transfer), you can transfer a database from a third-party MySQL cluster to your [Yandex Managed Service for MySQL](https://yandex.cloud/docs/managed-mysql) cluster. See [this tutorial](https://yandex.cloud/docs/data-transfer/tutorials/managed-mysql) to learn how to set up the solution with Terraform. This repository contains the configuration file you will need: [data-transfer-mysql-mmy.tf](data-transfer-mysql-mmy.tf).
